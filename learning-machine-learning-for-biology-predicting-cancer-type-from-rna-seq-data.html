4 Learning machine learning for biology: predicting cancer type from RNA-seq data

4.1 Why this skill

In my vacancy analysis, statistics and machine learning were requested in several vacancies and are only partly covered by my current skills. I apply the skill to a biological question: can a machine learning model distinguish cancer types (or subtypes) based on gene and which genes and processes drive it

4.3 How I will show I learned the skill

  • A reproducible analysis (Rmd or notebook, with code in a GitHub repository). with the code explained step by step
  • Data preparation and a proper train/test split
  • At least two models
  • Evaluation with a PCR matrix, plus a figure of the most important genes with a GO enrichment plot and whether they make biological sense.
  • A reflection on limitations: many more genes than samples, overfitting, and what the model can and cannot say.
